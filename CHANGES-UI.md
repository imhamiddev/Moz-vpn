# UI v1 — Modern minimal (blue)

- Theme: new blue palette. Light = white surfaces + blue accent; Dark = black surfaces + bright blue. Dynamic (wallpaper) color is now OFF by default so the look is consistent.
- Shapes: larger rounded corners (12/16/22/28dp).
- Home: new connect button (gradient + glow + pulse ring while connecting/connected), cleaner status/timer, rounded bordered cards (Location, Current IP + badge, Data Used / Latency tiles, Quota).
- Login/Splash: icon badge, rounded fields and 54dp buttons.
- Server list: rounded row cards, primary-colored selected check.
- Settings: bolder section labels (everything else inherits the new palette).
- All app logic is unchanged.
